SCENE: foreground audio demonstration

Review reference for com.eastnoise.scene.frequency, version 1.0.0 (3).

This screen recording was captured on August 27, 2026, in the earlier SCENE build. The September 10 update preserves the audio engine, headphone requirement, microphone processing, foreground service, and media-session behavior. The on-screen scene name STILL is now CALM. This is an emulator demonstration, not a physical-device audio-quality test.

The recording shows user-initiated playback, an active session with the microphone indicator, and leaving the app while the session continues. Media playback and live microphone input belong to the same session. Microphone audio is processed on device in memory and is never saved or uploaded.
